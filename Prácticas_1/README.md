## 📂 Ejercicios Implementados

### ☕ Ejercicio 1: Simulación Multijugador (Java)
* [cite_start]**Patrón:** Abstract Factory + Factory Method[cite: 48].
* [cite_start]**Descripción:** Simulación de partidas competitivas y casuales iniciadas simultáneamente mediante hebras (`Runnable`)[cite: 39, 50, 51].
* [cite_start]**Características:** Gestión de desconexiones (10% - 20%) y duración de 60 segundos por partida[cite: 41, 42, 43].

### 🤖 Ejercicio 2: Decorador de LLM (Python)
* [cite_start]**Patrón:** Decorator[cite: 67].
* [cite_start]**Descripción:** Extensión dinámica de un modelo de lenguaje (Hugging Face API) para añadir traducción al español y análisis de sentimientos[cite: 68, 69].
* [cite_start]**Configuración:** Parámetros gestionados a través de un archivo `config.json`[cite: 70, 91].

### 🏒 Ejercicio 3: Web Scraping de Hockey (Python)
* [cite_start]**Patrón:** Strategy[cite: 106].
* [cite_start]**Descripción:** Extracción de estadísticas de 5 páginas del sitio *Scrape This Site*[cite: 106].
* [cite_start]**Estrategias:** * **BeautifulSoup:** Para HTML estático[cite: 119].
    * [cite_start]**Selenium:** Para procesamiento del DOM en modo headless[cite: 120].

### 💎 Ejercicio 4: Filtros de Autenticación (Ruby)
* [cite_start]**Patrón:** Intercepting Filter[cite: 124].
* [cite_start]**Descripción:** Cadena de filtros para validar credenciales de usuario (formato de correo y reglas de seguridad de contraseña)[cite: 125, 126, 129].
* [cite_start]**Tecnologías:** Implementado obligatoriamente en Ruby[cite: 132].

### 🌡️ Ejercicio 5: Adaptador Domótico (Individual)
